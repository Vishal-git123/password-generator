# 🔐 Password Generator

A modern, secure, and user-friendly password generator built with **HTML**, **CSS**, and **JavaScript**. Generate strong random passwords with fully customizable options to meet any security requirement.

---

## ✨ Features

- 🎲 **Generate Strong Passwords** - Creates cryptographically secure random passwords
- 🔤 **Customizable Character Sets**
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Symbols & Special characters
- ⚙️ **Adjustable Length** - Set password length from minimum to maximum
- 📋 **One-Click Copy** - Easily copy generated password to clipboard
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- 🎨 **Clean UI** - Intuitive and modern user interface
- ⚡ **Real-time Generation** - Instant password generation with custom settings

## 🚀 How to Use

1. **Clone or download** this repository
2. **Open** `index.html` in your web browser
3. **Select** your password preferences:
   - Toggle character types (uppercase, lowercase, numbers, symbols)
   - Adjust password length using the slider or input
4. **Click** the "Generate" button to create a password
5. **Copy** the password to clipboard with one click
6. Use the generated password for your accounts!

---

## 💡 Features in Detail

### Character Selection
Choose which types of characters to include:
- **Uppercase** - Adds A-Z characters
- **Lowercase** - Adds a-z characters
- **Numbers** - Adds 0-9 digits
- **Symbols** - Adds special characters (!@#$%^&*, etc.)

### Password Length
Customize the length of your password to match security requirements:
- Minimum recommended length: 8 characters
- Maximum: As per your needs
- Use slider or type directly

### Copy to Clipboard
- Click the copy button to instantly copy the generated password
- Visual feedback confirms successful copy

---

## 🔒 Security Notes

- Passwords are generated using JavaScript's `Math.random()` and character pool selection
- No passwords are stored or transmitted to any server
- All generation happens locally in your browser
- For production use cases, consider cryptographic libraries like `crypto-js`
